A tiny program for make.fun's [One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629) bounty. It writes one deadpan one-star review, 160 characters or fewer, of an everyday essential (water) to `/output/entry.txt`:

> One star. Water falls from the sky for free, is banned at security, then sold back to me for four dollars. Same water.

Run it with Node 22+:

```
node main.ts
```

The output is deterministic: every run writes the same line, byte for byte.
